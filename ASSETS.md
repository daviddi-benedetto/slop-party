Everything Slop Party ships, where it came from and what we are allowed to do with it. Short version: **every 3D model is CC0 (public domain)** — free to use, modify and sell, with no attribution required — and everything else is either generated by our own code or under a permissive licence listed here. Nothing in the game needs a paid licence or carries a non-commercial or share-alike condition.

This file is generated from the model folders (`assets/models/`). When you add a model, add it here too.

## Where the models were downloaded

All models were downloaded as `.glb` files from the public asset library of the GDevelop game engine (index: `https://resources.gdevelop-app.com/assets-database/assetShortHeaders.json`, files on `asset-resources.gdevelop.io`), which mirrors these packs and labels each one "CC0 (public domain)". The authors publish the same packs, also as CC0, on their own sites (linked below). The Fantasy Props models had their shared textures moved out of each file into `assets/models/fantasy/tex/` to save space; nothing else was altered.
